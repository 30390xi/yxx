# 游陕西小程序还原工作区

## 在微信开发者工具运行

1. 使用 JDK 8 在 `backend-java8/` 执行 `./run.sh`，本地接口与管理页启动在 `http://127.0.0.1:8787`。
2. 将 `runnable-miniapp/` 导入微信开发者工具并选择“小程序”；工程 AppID 为 `wxf8549078eee81f5f`。
3. 选择“普通编译”。首页“查攻略”可进入攻略列表并打开线路详情；“找景区”可查看景区与门票商品。
4. 管理页地址为 `http://127.0.0.1:8787/admin`，可检索、查看和编辑已抓取的 JSON 响应。

现有 46 条公开接口样本、38 条本地 GET 路由及 566 张抓取图片。`backend-java8/verify_local_routes.js` 可核对本地 GET 地址。接口字段见 `backend-java8/接口字段.md`。

## 工程说明

- `runnable-miniapp/`：可导入开发者工具的编译源码与本地图片，详见其 `README.md`。
- `backend-java8/`：JDK 8 样本接口后台、HAR 导入和图片缓存脚本，详见其 `README.md` 与 `TRD.md`。
- `reconstruction/`：原包静态分析、页面与请求索引、客户端加密逻辑，详见 `逆向报告.md`。
- `PRD.md`：目标、流程、验收与当前缺口。

原服务不接受当前 AppID 的登录会话，登录后的下单和支付尚未验证；原包中另有 111 个空白页面。当前工程用于本地还原与调试，尚不具备发布验收条件。
