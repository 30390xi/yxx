# 游陕西接口样本后台

基于微信开发者工具中实际收到的公开接口响应，提供 Java 8 可运行的本地 API 和数据管理页。它是接口样本后台，适合复刻页面与联调；用户认证、订单、支付等尚无可靠运行时返回证据，因此没有伪造这些功能。

## 运行

macOS 已安装 JDK 8 时：

```sh
./run.sh
```

打开 [管理页](http://127.0.0.1:8787/admin)。可选择接口查看和编辑 JSON，保存后本地接口立即返回新内容。默认只监听本机 `127.0.0.1`，端口可用 `./run.sh 8788` 修改。

接口例子：

```sh
curl 'http://127.0.0.1:8787/product/app/v1/line/product/home/list?current=1&size=11'
```

运行 `node verify_local_routes.js` 可核对全部 GET 样本在“参数写在 URL”及“参数作为请求对象”两种调用方式下都会生成正确的本地地址。

路由按 HTTP 方法、路径和查询参数精确匹配。未知接口返回 HTTP 404 和 `{code,data,msg,success}` 错误体。POST 样本目前未按照请求体细分。

## 数据来源与范围

`fixtures/` 中只保留原始后台的公开浏览响应及其字段；抓包中的微信登录 code、请求头、Cookie、令牌和原始 HAR 均未进入此项目。现有 46 条样本（38 条 GET、8 条 POST），涵盖首页、景区筛选与详情、门票商品、攻略和线路商品列表及详情。图片原始 URL 仍保留在样本中，小程序工程另将已抓取的 566 张图片映射到本地文件。字段索引见 [接口字段.md](接口字段.md)。

从微信开发者工具导出 HAR 后，运行 `python3 ingest_devtools_har.py /path/to/capture.har`。脚本提取公开 JSON 与图片请求；HAR 包含图片正文时直接保存响应字节，否则按已观察 URL 缓存图片。提取后立即删除原始 HAR，再生成客户端路由及图片映射。原始 HAR 可能包含会话数据，请勿手动归档或提交。客户端路由仅为精确匹配的 GET 样本；其余请求仍使用原接口。

## 限制

- 该服务重放已观察到的响应，不代表完整原始后台业务规则。
- 所用 AppID `wxf8549078eee81f5f` 与原服务登录会话未对上；会话接口观察到的是失败返回，故未实现真实登录。
- `fixtures` 可直接编辑，也可通过管理页编辑。请勿将含私人数据的响应添加到此目录。
