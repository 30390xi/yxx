## 代码说明

- `app.js`、`common/runtime.js`、`common/vendor.js`、`common/main.js` 是启动链。
- `app.json` 列出主包和分包；`pages/`、`subPage/`、`subPack/`、`yearCard/`、`union/` 等保留页面代码和视图。
- 这是**可运行的编译源码**，不能等同于原始 uni-app `.vue` 工程。若要重建 `.vue`，需逐页改写；工作区 `reconstruction/` 提供模块抽取和接口索引。
- 原包中的 `distribution`、`artShow`、`xr`、`chat`、`escortPage`、`smqc` 共 111 个声明页面是空白模板；本工程保留其现状，不假称这些业务已实现。
- `common/captured-api-routes.js` 将与抓包记录**方法、路径及查询参数完全一致**的 1196 个公开 GET 请求发往本地 JDK 8 后台 `127.0.0.1:8787`，其中包括目的地页 11 个城市的前两页景区列表。首页广告和权益卡列表另按页面源码中的完整请求体精确匹配，命中时使用本地 POST 样本；其他 POST 仍走原接口，因为样本索引尚未按请求体区分。查询参数可来自接口路径或请求对象；本地 GET 只发送一次参数。后台不可达或该条样本返回非 200 时，请求层恢复原参数并回退到原接口；未记录的请求直接走原接口。
- `static/captured/` 保留 1257 张页面引用图及代表性接口图片（约 184 MiB）；其余缓存图已删除。`common/captured-image-map.js` 只映射保留的图片，接口样本中的原始 URL 仍可用于按需加载；WXML 中直接引用的 549 个本地图片路径均已核对存在。WXSS 中一张较小的背景图使用已抓取文件生成的 data URI。开发者工具 Network 面板已验证本地图片返回 HTTP 200；未缓存图片依赖原图床。
