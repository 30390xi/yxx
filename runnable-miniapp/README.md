## 代码说明

- `app.js`、`common/runtime.js`、`common/vendor.js`、`common/main.js` 是启动链。
- `app.json` 列出主包和分包；`pages/`、`subPage/`、`subPack/`、`yearCard/`、`union/` 等保留页面代码和视图。
- 这是**可运行的编译源码**，不能等同于原始 uni-app `.vue` 工程。若要重建 `.vue`，需逐页改写；工作区 `reconstruction/` 提供模块抽取和接口索引。
- 原包中的 `distribution`、`artShow`、`xr`、`chat`、`escortPage`、`smqc` 共 111 个声明页面是空白模板；本工程保留其现状，不假称这些业务已实现。
- `common/captured-api-routes.js` 将与抓包记录**方法、路径及查询参数完全一致**的 38 个公开 GET 请求发往本地 JDK 8 后台 `127.0.0.1:8787`。查询参数可来自接口路径或请求对象；本地请求只发送一次参数。后台不可达或该条样本返回非 200 时，请求层恢复原参数并回退到原接口；未记录的请求直接走原接口。POST 请求因抓包样本未按请求体区分，仍走原接口。
- `static/captured/` 有 566 张从实测公开接口响应和开发者工具图片网络记录取得的图片；`common/captured-image-map.js` 本地化已缓存的接口图片。WXML 中已观察到的硬编码图片地址改为本地路径；WXSS 中一张较小的背景图使用已抓取文件生成的 data URI，因为 WXSS 无法直接加载本地背景图。开发者工具 Network 面板已验证本地图片返回 HTTP 200。尚未访问的页面和新出现的接口图片可能继续依赖原图床。
- 攻略列表卡片使用原生 `navigator` 打开线路详情，已在开发者工具中验证“查攻略 → 西安精华景点3日游攻略 → 线路详情”。该详情接口由本地后台返回 HTTP 200。原地图密钥与新 AppID 不匹配，详情页使用抓取的路线节点展示线路地图。
- 修复了还原模板中的 496 处 `$orig` 属性引用和 13 处安全区数值拼接，避免商品标签显示 `undefined`、底栏覆盖整页。
- 已修复编译包中的对象字面量 WXML 绑定，使景区筛选等分包可编译。修复脚本位于 `reconstruction/fix_wxml_literals.py`。
